# Проект API-тестов для сервиса Самокат
---
## Тесты:
Файлы хранятся в директории /tests и разделены по директориям:

## сourier: эндпоинты, касающиеся действий с курьерами

### test_create_courier.py
Тесты для проверки эндпоинта на создание курьерского аккаунта

#### test_create_courier_success
Проверяется код и текст успешного ответа при создании аккаунта 

#### test_create_courier_existing_user_error
Проверяется код и текст ответа при попытке повторного создания аккаунта с теми же реквизитами 

#### test_create_courier_missing_field_error
Проверяется код и текст ответа при попытке создания аккаунта без одного из обязательных полей

### test_login_courier.py
Тесты для проверки эндпоинта на аутентификацию в курьерский аккаунт

#### test_login_courier_success
Проверяется код и текст успешного ответа при аутентификации в аккаунт

#### test_login_courier_missing_field_error
Проверяется код и текст ответа при попытке аутентификации в аккаунт без одного из обязательных полей

#### test_login_courier_incorrect_field_error
Проверяется код и текст ответа при попытке аутентификации в аккаунт с некорректным значением одного из 
обязательных полей

#### test_login_courier_not_exists_error
Проверяется код и текст ответа при попытке аутентификации в аккаунт с несуществующими в БД реквизитами

## order: эндпоинты, касающиеся действий с заказами

### test_create_order.py
Тесты для проверки эндпоинта на создание заказа

#### test_create_order_success
Проверяется код и текст успешного ответа при создании заказа с разным значением поля 'color'

### test_get_orders.py
Тесты для проверки эндпоинта на получение данных о заказах

#### test_get_all_orders_success
Проверяется код и текст успешного ответа при запросе без параметров (данных всех заказов)

## Методы эндпоинтов
Хранятся в директории /methods

### courier_methods.py
Методы для взаимодействия с курьерами
- post_create_courier - отправляет POST-запрос на создание курьерского аккаунта
- post_login_courier - отправляет POST-запрос на аутентификацию в курьерский аккаунт
- delete_courier - отправляет POST-запрос на удаление курьерского аккаунта

### order_methods.py
Методы для взаимодействия с заказами
- post_create_order - отправляет POST-запрос на создание заказа
- get_orders - отправляет GET-запрос на получение данных заказа по параметрам

## Прочие файлы:

Также в проекте есть другие файлы, которые используются при запуске тестов. Они хранятся в корне проекта

### conftest
Файл с фикстурами 

- generate_user_data - создает произвольный набор валидных данных для регистрации/аутентификации в аккаунт курьера и
  возвращает его
- register_and_return_user_data - создает произвольный набор валидных данных для регистрации, создает аккаунт курьера и
  и возвращает этот набор данных, после выполнения теста удаляет созданный аккаунт
- generate_order_data - создает произвольный набор валидных данных для создания заказа и возвращает его
